# Stage 1：离线靶场单虚拟手柄闭环候选

用户明确授权建立并连接虚拟手柄，范围为本地离线APEX靶场，AI负责RX/RY瞄准及RB开火/LB瞄准。
用户确认10%阈值检查左右四轴；其他按键透传；不需要前台窗口门控，用户认为游戏自行暂停后台输入。
本实现不自动启动游戏、不安装其他手柄驱动、不修改键鼠，不支持网络比赛。

用户在PyCharm运行setup_c2_controller.py，使用.venv-yolo解释器、FPS工作目录，参数留空。
该入口核对签名，打开官方安装器/UAC；由用户完成安装并手动重启，不自动隐藏设备/重启。

F9暂停/恢复AI，F10退出。没有窗口焦点判断，按用户偏好运行。

无法验证就恢复并退出，不带冲突继续运行。游戏已有设备缓存可能需要用户重连手柄/重启游戏。
HidHide不会把USB设备物理合成；它隔离真实设备，游戏只接收合并器输出的一个虚拟Xbox360。

## 接管与按钮

启动先人工模式。LX/LY/RX/RY任一轴绝对值>0.10，立即人工接管，直接透传真实完整报告。
四轴全部<=0.10持续1秒后返回AI；一次超过阈值会清空计时。F9暂停也清空计时。
人工模式仍走同一个虚拟设备，不在切换时反复插拔/取消隐藏；运行结束才恢复物理可见性。
人工模式RX/RY/RB/LB立即由用户接管，不延迟等待AI惯性；AI已按下的RB/LB不会叠加保留。
AI模式LX/LY、LT/RT和其余原始按钮继续透传；RX/RY来自C2+bias+80ms候选轨迹。
恢复AI从最后人工输出的右摇杆位置开始，不重置为任意模型值。

AI RB采用0.65按下、0.35释放滞回，LB采用0.6/0.4；这些阈值是候选配置，不是新训练成果。
开火还要求新鲜、有效选定敌人，且屏幕中心位于该框内部；目标丢失/过期或人工接管立即取消AI按钮。
没有固定延长开火时长。滞回只能减少阈值附近抖动，不能承诺解决原模型的大幅按钮切换。
RX/RY目标和BC源年龄任一超过150ms，AI轨迹软回中；断连/采集错误则整轮终止并发中立报告。
手柄不存在统一“10%按钮”阈值，这次按用户确认只检查四轴，不用LT/RT/LB/RB触发接管。

## 回报和数据

请求约1ms合并报告循环，实际使用QPC记录；不声称Windows/USB/游戏真实1000Hz。
每次调用virtual.update记录输入观察、决策、驱动API返回、模式和完整实际发送报告。
输出runs/c2_closed_loop/<时间>：run_config.json、executed_actions.csv、perception.jsonl、summary.json。
API返回时间不是游戏收到动作或显示器显示的时刻，不能将其当作完整捕获到动作延迟。
用户报告射击命中率时最好同时报告发射/命中次数；单个回合总分不自动成为每帧RL奖励。
本轮固定bias/惯性与现有C2权重，尚未训练RL。
