# 用户APEX键位

以用户提供的键位截图及明确文字“LB瞄准、RB开火”为准。
机器配置apex_controller_bindings.json，C2直接读取输出顺序及标签版本。

|功能|手柄键|说明|
|---|---|---|
|瞄准/开镜|LB|按住|
|攻击/开火|RB|数字按钮|
|跳跃|RT|扳机，跳跃绑定；阈值未校准|
|蹲伏|LT|按住；阈值未校准|
|交互/拾取/换弹|X|由游戏上下文决定|
|切换武器/收枪|Y|按住收枪|
|战术技能|LS|按下左摇杆|
|标记/标记轮盘|B|按住轮盘|
|冲刺/切换倍率|RS|按下右摇杆|
|近战|A|数字按钮|
|治疗/护盾道具|方向上|按截图|
|额外角色动作|方向下|按截图|
|切换射击模式|方向左|按截图|
|装备手雷|方向右|按截图|
|地图|View|切换|
|终极技能|LS+B|组合键|

当前C2仅预测RX/RY/RB/LB，不因收到完整截图自动扩展到其他动作。
RX/RY为右摇杆轴，RS为右摇杆按键，必须区分。
旧LT/RT语义训练不适用于本用户的开火/瞄准；旧数据集day1234_bc_v1和旧权重保留但不继续使用。
新数据集day1234_bc_rb_lb_v2按原始gamepad.csv的rb/lb字段重建动作标签，不是重命名旧rt/lt数值。
单段重新选择DAY2 episode15，要求包含按下和释放开火，缓存与模型回执固定action_schema以拒绝旧标签。
记录配置不代表已实现虚拟手柄输出。
