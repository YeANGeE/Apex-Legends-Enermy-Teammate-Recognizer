# C2单目标跟随意图诊断

用户确认离线靶场是训练假人，C1敌人框基本正确。当前C2联合GameInput候选实时行为未通过，
停止重复该候选的实时测试；不启用闭环控制。靶场假人与比赛角色存在分布差异，不能断言单一根因。

prepare_c2_target_review.py仅准备已有train/val缓存的候选复核；测试/诊断片段不参与。
首批输出runs/c2_target_review/20261010_231628_310735/review.html，12段训练候选、4段原验证。
每DAY最多3段训练候选，原验证始终保持验证身份。抽取原视频中确切frame_id的1080p帧，
使用既有源时间和GameInput标签，没有新训练、目标标签替换或未来动作对齐。

自动筛选只表示C1 top8特征中一个enemy假设满足置信度/面积/短期位置门限，
不证明真实单敌人、跟踪身份一致或玩家正在瞄准它。
用户在浏览器打开review.html，慢放/逐帧查看黄色候选框和真实RX/RY/RB/LB，逐段选可用/不确定/不可用。
仅在整段候选为同一真实敌人且玩家在跟随/接近瞄准它时选可用；框错、转火或观察动作不算跟随。
复核完成点保存复核JSON，下载c2_target_intent_review.json，候选文件SHA随之导出以防错配。
这是小规模诊断筛选，不是完整训练集；不可把少量复核自动扩展到所有未复核片段。

候选提取完整执行通过，8项目标筛选和C2基础测试通过。人工检查了一张原始1080p帧；
尚未人工确认全部目标或真实跟随意图，也未完成浏览器交互验收。
这步目的是判断目标条件、动作标签和行为阶段的可靠性，再决定窄任务建模；
不自动启动训练，不用规则输出代替学到的策略。
