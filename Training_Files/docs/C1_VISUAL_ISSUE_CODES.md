# Stage 1 — Local Combat Policy：固定视觉问题代码

反馈格式：片段编号，秒数或区间，问题代码，可选人物位置描述。同一处可有多个问题。字母/数字是问题代码，不是人物编号。后续不重新分配已定义的含义。

|类别|固定代码|
|---|---|
|A 框的位置与大小|A1 偏移；A2 过大；A3 过小；A4 抖动；A5 滞后|
|B 误检|B1 场景；B2 特效；B3 界面文字或图标；B4 尸体/倒地等非目标状态检出，目标定义待明确，不能自动判错|
|C 重复检测|C1 同类重复；C2 同一人敌人/队友双框；C3 局部与整体重复|
|D 漏检|D1 持续；D2 间歇；D3 出现后迟检；D4 远小/模糊/遮挡/边缘/特效中漏检|
|E 敌我分类|E1 队友认成敌人；E2 敌人认成队友；E3 类别反复；E4 ID/血条/遮挡状态变化后认反|
|F 跟踪编号|F1 同一人断号或换号；F2 两人串号；F3 遮挡后接错人|

用户反馈是定性验收依据；日志计数和几何重叠不是人物真值。不能把全片空检测帧都算漏检，也不能把所有框重叠都算重复。原始检测与跟踪/渲染错误分层诊断，未经确认不修改训练或独立验证标注。
